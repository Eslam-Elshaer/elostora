Elostora v5 - نسخة مجانية أولية قابلة للتثبيت والعمل دون اتصال لبعض الملفات

التشغيل محليًا:
1) فك الضغط وافتح المجلد في VS Code.
2) شغّل Live Server من ملف index.html.
3) اسمح بالإشعارات من زر «تفعيل الإشعارات».

الجديد في v5:
- إضافة Service Worker وكاش للملفات الأساسية، بحيث يمكن فتح نسخة الموقع بعد تحميلها أول مرة في بيئة تدعم Service Worker.
- يمكن للمتصفح عرض خيار تثبيت الموقع كتطبيق إذا استوفى شروط التثبيت.

الموجود حاليًا:
- المحاضرات والسكاشن والمراجعات، وبنك المهام وخطة بكرة.
- حفظ البيانات محليًا في المتصفح نفسه.
- التنبيهات المجدولة محليًا تعمل أثناء فتح الموقع فقط.

مهم جدًا:
هذه النسخة لا ترسل إشعارات مجدولة بعد إغلاق الموقع، ولا تشارك بيانات المستخدمين بين الأجهزة. Service Worker والكاش وحدهما لا يكفيان لإرسال Push Notifications؛ هذا يحتاج اشتراكات إشعارات وخدمة خلفية وقاعدة بيانات.

النشر المجاني:
يمكن نشر الملفات الثابتة مثل هذه النسخة على GitHub Pages مجانًا وبـ HTTPS. لكن GitHub Pages وحده لا يوفر قاعدة بيانات مشتركة أو خادمًا لإرسال الإشعارات. سنضيف ذلك في خطوة مستقلة، مع مراعاة شروط وحدود الخدمات المجانية وعدم وضع أي مفاتيح سرية داخل ملفات الموقع.


تثبيت Elostora على Android (بعد رفع ملفات هذه النسخة إلى GitHub Pages):
1) افتح https://eslam-elshaer.github.io/elostora/ في Google Chrome على الموبايل.
2) اضغط قائمة الثلاث نقاط ⋮.
3) اختار Install app / تثبيت التطبيق أو Add to Home screen / إضافة إلى الشاشة الرئيسية.
4) افتح التطبيق من الأيقونة واضغط تفعيل الإشعارات واسمح بها.

مهم: البيانات محفوظة محليًا على نفس المتصفح/الجهاز. لا توجد حسابات أو مزامنة. تذكيرات الوقت داخل app.js تعتمد على أن الصفحة تعمل؛ لا نضمن تشغيل المنبه بعد إغلاق التطبيق بالكامل أو إيقاف النظام له.
